# Workbench Recruit — learning example

Original plugin source clones Commando's native body/display and retains native
skills, movement, input and camera. No game asset bytes are included in this ZIP.

This is a compile-verified development example. Survivor selection, stock prefab
resolution, actual game API access, physical controller and host/client behavior
remain pending. Do not treat the review ZIP as a tested release.

Use normal native Commando controls after an authorized disposable-profile test.
Every player needs the same example version and listed dependencies. There is
no custom art, audio, effect, input binding or loadout redesign in this first slice.

Original code: MIT, RoR2 Survivor Workbench contributors. BepInEx/R2API remain external
dependencies. Risk of Rain 2 and its assets belong to their respective owners.
This unofficial learning project is not affiliated with the game developers.
