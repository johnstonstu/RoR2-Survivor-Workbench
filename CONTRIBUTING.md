# Contributing

Use a focused task with explicit acceptance and disjoint ownership. Read AGENTS.md.
Keep the CLI usable from a checkout using only Python's standard library.

Before proposing a change, run the unit suite and demo. Include the smallest
failure case that the change fixes, the exact scope verified, and anything
left unverified. Never submit local profiles, saves, session transcripts, raw
personal logs, game assemblies, decompiled source or extracted assets.

Original contributions are offered under the repository's MIT
license. For adapted material, identify its source, revision, license and
required notices first. A public repository without a license is not permission
to copy it. Cite a pattern rather than vendoring uncertain implementation.

Publish repository changes or releases only with the maintainer's explicit
authorization. The CLI does not publish. Review the complete proposed Git
history as well as the current tree; use a privacy-safe commit identity and
never submit personal email addresses, exports or operational evidence.
